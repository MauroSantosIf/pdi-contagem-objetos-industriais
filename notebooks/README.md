# Notebooks do Projeto

Esta pasta contém os notebooks utilizados no desenvolvimento
do projeto de Processamento Digital de Imagens.

## Fases

- Fase 1: Organização dos datasets e construção do Ground Truth.
- Fase 2: Pré-processamento de imagens.
- Fases futuras: Detecção, classificação e contagem de objetos.

Os notebooks devem ser mantidos separados por fase,
com documentação das técnicas e resultados.
